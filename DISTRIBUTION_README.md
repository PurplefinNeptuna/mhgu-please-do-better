# Please do Better

Highlights extra quest reward slots granted by luck with a pulsing gold border
and small sparkle. A gold marker shows which extra slot came from luck.

## Requirements

MHGU 1.4.0 for Nintendo Switch and Forge 1.4.1.

## Installation

1. Close Eden.
2. Extract `please-do-better-r16.zip`.
3. Copy the `please-do-better` folder into
   `~/.local/share/eden/load/0100770008DD8000/`.
4. Enable `please-do-better` in Eden and launch the game.

## Settings

Open **Plugin UI > Please do Better** in Forge's overlay.

By default, the mod highlights rewards from your hunter's natural luck.
Enable **Force Miraculous Luck** to use Miraculous Luck for subsequent reward
batches. Select **Save settings** to keep your choice for future sessions.

## Known issue

Forge's menu can show visual corruption while reward highlighting is active.
Adjust settings outside the reward screen and close the overlay menu when
viewing marked rewards.
