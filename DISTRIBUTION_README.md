# Please do Better r16

Highlights extra quest reward slots enabled by positive luck with a pulsing gold
border and small sparkle in Monster Hunter Generations Ultimate 1.4.0 for
Nintendo Switch. Fresh installs use natural luck. The optional **Force Miraculous
Luck** setting works without an equipped luck skill.

A gold marker means luck enabled an extra slot compared with normal luck using
the same rolls. It does not guarantee rare items, maximum rewards or extra carves.
Empty or unsupported slots remain unmarked. Crafting, equipment unlocks and
inventory are unchanged.

## Requirements and compatibility

Requires Forge 1.4.1 on the tested Eden/Linux setup; Forge and Better Input are
supplied separately. Disable the legacy Great Luck cheat, including the old
cheat package also named Please do Better.

An earlier release's visible reward markers were confirmed on one Eden reward
grid. r16 has not had a separate gameplay test. Natural luck, broader quest and
settings combinations, repeated reward screens and saved-setting persistence
remain unverified. Ryujinx and native Switch hardware are untested.

## Install or update

1. Close the emulator.
2. Extract `please-do-better-r16.zip`. Copy its `please-do-better` folder into
   Eden's MHGU mod directory, `~/.local/share/eden/load/0100770008DD8000/`,
   alongside Forge.
3. When updating, back up the old package outside that directory and replace it.
   Keep only one copy of the plugin installed and disable the legacy cheat.
4. Enable the package and restart the game.

To remove it, close the emulator, disable or remove `please-do-better`,
then restart. Restart after adding, removing or replacing this plugin.

## Settings

Open **Plugin UI > Please do Better** in Forge's overlay when reward highlighting
is inactive. Closing settings leaves reward highlighting active.

**Force Miraculous Luck** affects subsequent reward batches; already-generated
rewards stay unchanged. Toggling this setting does not require a restart.
**Save settings** keeps your choice for the active player in
`please_do_better.ini`, with a recovery copy beside Better Input's settings.
Without a valid saved preference, forcing starts off.

## Known issue

Forge's menu can show visual corruption while reward highlighting is active.
Adjust settings outside active highlighting and close the Forge menu when
viewing marked rewards.

## Sharing and support

Keep `NOTICES.txt` with the ZIP when sharing it. When reporting a problem,
include your emulator/game version, luck settings, affected quest or reward
screen, other enabled mods and a fresh emulator log.
