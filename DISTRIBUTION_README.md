# Please do Better

Highlights extra quest reward slots granted by luck with a pulsing gold border
and small sparkle. A gold marker shows which extra slot came from luck.

## Requirements

MHGU 1.4.0 for Nintendo Switch and Forge 1.4.1.

## Installation

1. Close Eden.
2. Extract `please-do-better-r17-config1.zip`.
3. Copy the `please-do-better` folder into
   `~/.local/share/eden/load/0100770008DD8000/`.
4. Enable `please-do-better` in Eden and launch the game.

To update, replace the existing `please-do-better` folder with the extracted
folder. Keep one copy of `please_do_better.nro` among your enabled mods.
To remove the mod, disable or remove its folder in Eden's mod directory.

## Settings

Open **Plugin UI > Please do Better** in Forge's overlay.

By default, the mod highlights rewards from your hunter's natural luck.
Enable **Force Miraculous Luck** to use Miraculous Luck for subsequent reward
batches. Select **Save settings** to keep your choice in `please_do_better.ini`
beside Better Input's config in player save storage.

If saving fails, the current choice remains active for the session. Load a
player save and retry **Save settings**.

## Known issue

Opening a dropdown or displaying gameplay overlays can make Forge's entire
ImGui window blank. If this happens, click random places inside that ImGui
window until the menu reappears.
